# 📊 AI Influence on Student Academic Performance
## 📌 Project Overview

This project analyzes how Artificial Intelligence (AI) usage affects student academic performance, engagement, lifestyle, and ethical behavior.
The interactive Power BI dashboard provides insights into student outcomes based on AI usage level, dependency risk, study habits, and ethical considerations.

The goal is to help educators, institutions, and decision-makers understand both the benefits and risks of AI adoption in education.

## 🎯 Objectives

Analyze overall student academic performance

Measure the impact of AI tools on learning outcomes

Identify AI dependency and ethical risks

Understand study habits, lifestyle patterns, and engagement

Compare performance across grades, gender, and AI usage levels

## 🗂 Dataset Description

The dataset contains student-level academic, behavioral, and AI usage data.

 ## Key Columns
Category	Fields
Student Info	student_id, age, gender, grade_level
Academic Performance	final_score, last_exam_score, assignment_scores_avg, passed, performance_category
Engagement	attendance_percentage, class_participation_score
AI Usage	uses_ai, ai_tools_used, ai_usage_time_minutes, ai_usage_purpose, ai_prompts_per_week
AI Risk & Ethics	ai_dependency_score, ai_ethics_score, ai_generated_content_percentage
Study & Lifestyle	study_hours_per_day, study_consistency_index, sleep_hours, social_media_hours, tutoring_hours
Improvement Metrics	improvement_rate, Score per Study Hour, Pass %

## 🔍 Key Findings

Moderate AI usage improves learning efficiency

High dependency on AI increases ethical risk

Balanced study hours and lifestyle are critical for success

AI should be used as a support tool, not a replacement for learning

## 🚀 How to Use

Download the .pbix file from this repository

Open in Power BI Desktop

Interact using slicers (Grade, Gender, AI Tool)

Explore insights across different dashboard pages

## 📌 Conclusion

This project highlights that AI can enhance academic performance when used responsibly, but excessive dependence may lead to ethical and learning challenges.
Educational institutions should promote ethical AI usage and balanced study practices.
